# LittleFootprints 🌱

自托管的**家庭成长档案**：记录孩子的兴趣爱好、成长经历（旅游、比赛、演出、聚会）、身高体重和活动照片，并可用 AI 生成每周的成长亮点报告。专为家庭内网设计，一个 6 位家庭 PIN 全家共用，数据完全留在自己家里。

> 适合想认真记录孩子成长、又不想把孩子的数据交给云服务的家庭。

## 功能

| 模块 | 说明 |
|------|------|
| 📖 成长时间线 | 记录旅游、比赛、演出、聚会、里程碑等成长事件，支持多孩共同参与；可关联相册目录或**直接上传现场照片/视频** |
| ⭐ 兴趣爱好 | 每个兴趣的状态（探索中/坚持中/暂停/结束）+ 进展记录，孩子也能自己记；**进行中的课程（如英语课）建为「学习」类兴趣**即可持续记录上课过程 |
| 📏 成长档案 | 出生日期、学校阶段、性格观察 + 身高/体重/**头围**记录与三指标生长曲线 |
| 💉 疫苗接种 | 按国家免疫规划一键生成应种计划（按出生日期推算），实际接种打勾，到期待种高亮提醒 |
| 📔 每日日志 | 每天一句话 + 心情 + 照片视频，按月归档；家长孩子都能写，AI 周报会结合日志观察情绪与生活节奏 |
| 🩺 身体状况 | 过敏源、基础疾病（哮喘等）基础信息卡；就诊/检查/疫苗接种记录，检查报告拍照或 PDF 上传；AI 结合健康状况理解活动安排（明确不做医疗诊断） |
| 📷 活动照片 | 关联 NAS/相册里的**活动目录**，照片不复制不上传，只读挂载直接浏览；支持视频在线播放 |
| ✨ AI 周报 | 接入任意 OpenAI-compatible 服务（云端或家庭内网），每周日自动生成分析报告；**孩子版亮点**只讲进步和本周小目标 |
| 👀 孩子视角 | 一键切换到孩子视角：只看自己的成长和照片、自己记兴趣进展，家长工具全部隐藏 |

### 隐私设计

- 单文件 SQLite + `data/uploads/` 附件目录，全部数据在你的机器上；定期备份 `data/` 目录即可
- 家庭 PIN 登录 + 失败限流；仅建议在家庭内网使用，不要暴露到公网
- AI 完全可选：不配置也能用全部记录功能；配置后可选家庭内网的本地模型，数据不出门
- 孩子版周报经过服务端裁剪，家长版分析内容（建议、费用等）不会出现在孩子视角
- 健康数据（过敏源、基础疾病、就诊记录）会作为背景上下文发送给您配置的 AI 服务用于分析，prompt 层面明确禁止 AI 给出诊断、用药或治疗建议；如介意，可不填基础信息或使用家庭内网本地模型
- 照片库只读挂载，系统无法修改或删除你的照片；照片不发送给 AI

## 快速开始（Docker）

需要一台内网常开的机器（NAS、小主机、树莓派均可）：

```bash
git clone https://github.com/xenolee0303-maker/LittleFootprints.git
cd littlefootprints

cp .env.example .env
# 编辑 .env：
#   FAMILY_PIN=6 位家庭 PIN
#   AI_CONFIG_ENCRYPTION_KEY=一串随机字符（用于加密 AI 密钥）
#   MEDIA_HOST_PATH=可选，照片库目录，启用活动照片功能

docker compose up -d --build
```

打开 `http://<机器IP>:3002`，输入家庭 PIN，创建第一个孩子就能开始用了。

### 作品与过程记录

兴趣进展和成长事件都可以直接**上传照片和视频**：画完的画 + 孩子讲解作品的视频、比赛现场录像、英语课的跟读片段等等，pad/手机上支持直接调用相机拍摄。进行中的课程（英语、钢琴陪练等）建为「学习」类兴趣，就能像记录兴趣一样持续记录上课过程。图片自动生成缩略图，视频在线播放；一条进展最多 9 个附件，单个文件默认上限 200MB（可用环境变量 `MAX_ASSET_SIZE_MB` 调整）。上传的文件保存在 `data/uploads/`，随数据目录一起备份。

### 启用活动照片（可选）

1. 在你的 NAS 相册里按活动建目录，建议命名 `YYYY-MM-活动名`（如 `2026-08-北京旅游`）
2. `.env` 里把 `MEDIA_HOST_PATH` 指向照片库根目录，然后 `docker compose up -d --force-recreate`
3. 在成长事件里「关联相册目录」，之后目录里新增照片会自动出现在事件下

支持常见图片格式和 mp4/mov 等视频；iPhone 的 HEIC 格式可列出但无法预览（建议相机设置选"兼容性最佳"）。

### 启用 AI 周报（可选）

设置 → AI 服务提供方：填入任意 OpenAI-compatible 服务的模型名、接口地址和密钥（云端或本地均可），点「测试连接」保存。之后每周日 20:00（Asia/Shanghai）自动为每个孩子生成周报，也可在设置里手动触发。

## 本地开发

```bash
npm install
npm run dev        # 后端 http://localhost:3002 · 前端 http://localhost:5174
npm test           # 全部测试
npm run typecheck  # 类型检查
```

技术栈：TypeScript monorepo（shared / server / web）、Fastify + Drizzle + SQLite（WAL）、React + Vite + Tailwind CSS + TanStack Query、sharp 缩略图、Docker 单容器部署。

## 与其他家庭系统联动

LittleFootprints 保持独立、无外部依赖。它的所有能力都通过 `/api/**` + 家庭 PIN 会话暴露，孩子用稳定的 UUID 标识——如果你同时运行学习排期类的系统，可以在任一侧通过 API 桥接两个系统的数据（例如把 LittleFootprints 的兴趣数据拉进另一侧的分析），两边仍然独立部署、独立备份。
